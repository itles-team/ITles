# ИТлес — производственный журнал

## Задача и читатель

Руководитель лесозаготовительного предприятия открывает парк, чтобы понять:
какие машины передавали данные, какие наблюдения устарели, какой объём записан
за период и откуда взялись эти числа. Интерфейс не определяет исправность
машины по свежести сообщения и не заменяет метрологическую проверку.

Первое действие нового посетителя — открыть явно вымышленный учебный парк
без пароля. Вход организации — отдельный путь для уже выданного доступа,
не неявная регистрация. Ошибки объясняются по-русски без раскрытия наличия аккаунта.

## Источники направления

- Пользовательский `DESIGN-everswap.com.md`: тёмно-зелёный, светлый фон,
  светло-лаймовый акцент, контраст редакционного заголовка и нейтрального текста.
  Не копируем логотип, DeFi-риторику, синий основной текст и гигантские размеры
  маркетинговой страницы в рабочий интерфейс. Britti Sans не включён: лицензия
  на этот шрифт не предоставлена.
- [anti-slop](https://github.com/miqdadbadjuber/anti-slop): функциональный смысл
  каждого элемента, отсутствие фиктивных цифр, единая система, живой ритм
  вместо стены одинаковых карточек. Использован как справочный фильтр,
  сторонние установщики и скрипты не запускались.
- [UX/UI Agent Skills](https://github.com/plugin87/ux-ui-agent-skills): разделы
  data-dashboard и redesign, семантические таблицы, состояния компонентов,
  проверка контраста и поведения в браузере. Не заявляем прохождение всех
  внешних gates без их выполнения.

## Design read

**ENERGY 2 / RHYTHM 3 / MOTION 1.** Спокойный рабочий инструмент, не лендинг
инвестиционного продукта. Опорный мотив — номера разделов и тонкие линейки
полевого журнала. Главный визуальный центр обзора — объём по отдельной базе
измерения. При отсутствии записей его место занимает честное пустое состояние.
Контрастная навигация отделяет инструменты от данных; пространство между
полосами разделяет сводку, исключения и построчный разбор.

## Токены

| Роль | Значение | Причина |
|---|---|---|
| Фон | `#F5F6EF` | Неослепляющий светлый рабочий лист |
| Поверхность | `#FFFFFF` | Таблицы и поля, требующие чтения |
| Основной текст | `#203727` | Тёмно-зелёная идентичность, достаточный контраст |
| Вторичный текст | `#596555` | Читаемые подписи, не бледные декоративные строки |
| Навигация | `#203727` | Отдельный устойчивый слой приложения |
| Акцент | `#E0FFAB` | Выбранное действие на тёмном фоне, не «всё хорошо» |
| Линия | `#D8DED1` | Группировка, не единственный признак поля |
| Граница поля | `#85917B` | Различимый контур интерактивных элементов |
| Предупреждение | `#825018` на `#FFF2DA` | Устаревшее наблюдение, не авария датчика |
| Ошибка | `#9B332B` на `#FFF0EC` | Невыполненный запрос или ошибочная запись |

Текст интерфейса — локальный Golos Text с кириллицей; редакционные заголовки —
локальный PT Serif. Системные fallback остаются доступными. Лицензии хранятся
рядом со шрифтами. Никаких запросов к Google Fonts при открытии приложения.
Основной текст 14–16 px, вторичный не мельче 12 px; числа табличной ширины.
Шаг пространства 4 px; основные интервалы 8/12/16/24/32 px. Скругления 4/8/12 px,
без универсальных «пилюль». Focus ring отдельный от состояния выбора.

## Структура

1. **Вход:** сначала объяснение продукта и учебный доступ без пароля;
   раскрываемый вход организации с пояснением, кто выдаёт доступ.
2. **Обзор:** отдельно суммы «без коры / с корой / база не указана»,
   полнота сообщений и список машин. Поиск и переход к конкретной машине.
3. **Карта:** подходящий масштаб принятых координат, кнопки масштаба и
   возврата ко всему парку, доступный список вместо обязательного клика в точку.
   Natural Earth — обзорная подложка, не карта дорог, лесных кварталов или границ работ.
4. **Карточка:** последние показатели с временем, статусом и пояснениями,
   отдельно журнал объёма за выбранный период. Не повторять одну оговорку
   под каждым из двенадцати показателей.
5. **Парк и объём:** таблица для сверки, точность реестра сохранена,
   смешанные методики явно отмечены. CSV — выгрузка, не интеграция с 1С.
6. **Качество, подключение, исследования:** журнал исходов пакетов (в демо —
   явно подписанные синтетические примеры, не результат реальной доставки),
   границы готовности, техническая инструкция и настоящие скачиваемые файлы.

## Непереговорные правила данных

- Учебный режим постоянно подписан; время его наблюдений не переносится
  к текущей дате. Нет анимации GPS и счётчиков «онлайн».
- Ноль — значение; `null` — отсутствие данных. Нет записей — не нулевая выработка.
- Базы объёма не складываются вместе; источник и предупреждения не прячутся
  ради красивого результата. Изменение моточасов не объявляется временем работы.
- Период относится к журналу; последние показания и координаты могут быть
  вне периода и подписываются отдельно.
- Не рисовать тренды без временного ряда, не вводить нормы без подтверждения.
- Без личных контактов, операторов, внешних тайлов и трекеров. Токены и пароли
  не попадают в URL, скриншоты и артефакты проверки.

## Состояния и доступность

Клавиатура, видимый фокус, Escape и возврат фокуса у модального окна,
помеченная выбранная навигация и машина; ошибки через `role=alert`.
Таблицы имеют подписи и заголовки; состояния не передаются одним цветом.
Основные зоны управления от 44 px; компактные пояснения — 28 px, вторичные
действия и поля — от 32 px. При 390 px навигация раскрывается,
обзор складывается в одну колонку; широкая таблица прокручивается внутри
своего контейнера, а не всей страницы. Проверить также 320 px и увеличение 200%.
Анимация только для обратной связи, выключается при reduced motion.

## Приёмка

Проверять реальным браузером: учебный вход → обзор → выбор машины → пояснение
→ реестр и CSV → качество → документы → выход. Отдельно: неверный вход,
нет координат, нет записей, нулевые значения, неизвестные и смешанные методики,
пустой/обратный период, потеря сети, истёкшая сессия, мобильное меню.
Результаты и незакрытые ограничения фиксировать в `docs/ux-review.md`.
Успешная сборка, DOM-тест и скриншот — разные доказательства, ни одно не заменяет
доступ к реальной машине или эталонному OEM-файлу.
