# Обзорная географическая подложка

`natural-earth-russia-region.geojson` — локальная выборка геометрии стран региона
из Natural Earth, Admin 0 Countries, масштаб 1:110m.

- Источник: https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/
- Условия: public domain, https://www.naturalearthdata.com/about/terms-of-use/
- В приложении нет запросов к внешнему серверу тайлов. Атрибуция показана на карте.

Это обзорная подложка, не навигационная карта лесовозных дорог и не источник
юридических границ или точных координат. Координаты техники поступают отдельно
из телеметрии. Номер upstream-релиза в исходной выборке не зафиксирован;
конкретная используемая копия геометрии версионируется в этом репозитории.
